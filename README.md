# 猜数字小游戏（play_do）

一个用 Python 写的命令行小游戏：程序随机想一个 1~100 的整数，你来猜，程序会提示“猜大了”或“猜小了”，直到猜中为止。全部在 Windows 命令提示符（cmd）里运行，不需要任何第三方库。

## 目录结构

```
play _do/
└── first/
    └── eeee.py      # 游戏源码
```

## 运行环境

- Windows 10 / 11 自带的「命令提示符」（cmd）
- Python 3.x（脚本只用标准库 `random`，已在 Python 3.14.6 上实测通过）

先确认 Python 可用：

```cmd
python --version
```

能打印出版本号（如 `Python 3.14.6`）即可。

## 用 cmd 运行

1. 按 `Win + R`，输入 `cmd`，回车，打开命令提示符。
2. 进入脚本所在目录。**路径中含有空格，必须加引号**：

```cmd
cd /d "D:\play _do\first"
```

3. 启动游戏：

```cmd
python eeee.py
```

也可以改用 Windows 的 Python 启动器：

```cmd
py -3 eeee.py
```

不想先切换目录，可以一行完成：

```cmd
cd /d "D:\play _do\first" && python eeee.py
```

在项目根目录运行也可以：

```cmd
cd /d "D:\play _do"
python first\eeee.py
```

> 上面的 `D:\play _do` 是本仓库在本机的位置，换到别的目录请相应替换。

## 玩法

- 程序在 1~100 之间随机取一个整数，不会显示出来。
- 每次输入一个整数：
  - 比答案大 → 提示 `猜大了，再试试！`
  - 比答案小 → 提示 `猜小了，再试试！`
  - 等于答案 → 提示 `恭喜！猜对啦，数字就是xx`，游戏结束。
- 输入的不是整数（字母、空行等）→ 提示 `请输入有效的整数！`，可以继续猜。
- 随时按 `Ctrl + C` 退出游戏。

## 常见问题

**1. 提示 `'python' 不是内部或外部命令，也不是可运行的程序`**

没有安装 Python，或安装时没勾选 “Add python.exe to PATH”。到 <https://www.python.org/downloads/> 下载安装，勾选该选项后重新打开 cmd。

**2. 提示 `Unable to create process using '...\python.exe'`**

Python 安装不完整（安装目录里缺少 `python.exe`）。用官方安装包对现有安装执行“修复”，或重新安装。

**3. 中文显示为乱码**

cmd 默认代码页 936，一般能正常显示。若仍乱码，先执行下面的命令切换为 UTF-8，再运行游戏：

```cmd
chcp 65001
```

**4. 双击 `.py` 文件时窗口一闪而过**

这是正常现象：程序结束后窗口立即关闭。请按上文方式在 cmd 中运行，或在脚本末尾追加 `input()` 让窗口停留。
